# MoonBit WebDAV 客户端实现计划

## 已确认的决策
- 上传：moonhttp 0.4.0 请求体为一次性字节，本次上传接口接受完整 `Bytes`，用 moonhttp 传输层 64KiB 分块发送的真实进度做上传进度回调；待 moonhttp 支持流式 body 后再同步升级（API 形态为此预留空间）。
- 下载：真流式（`Client::stream` + `read_some` 分块消费，WebDAV 层自行累计进度）。
- 扩展操作：DELETE 删除、exists 存在检查（HEAD）、PROPFIND 列目录/属性（list/stat）、PROPPATCH 属性读写（set_properties/get_properties）。不做 LOCK/UNLOCK。
- 项目 `preferred_target` 从 `wasm` 改为 `native`（moonhttp 基于 moonbitlang/async 异步运行时，仅 native 可用，技术必然）。

## 公开 API 契约

```moonbit
// src/types
pub(all) struct WebdavConfig { base_url : String; username : String?; password : String?; timeout_ms : Int? }

                           content_type : String?; last_modified : String?; created : String?; etag : String? }

pub fn Progress::percent(Self) -> Double?

                            Api(status~ : Int, operation~ : String, message~ : String) }  // derive Show

// src/client —— 方法全部 async raise WebdavError
pub fn create_webdav_client(WebdavConfig) -> WebdavClient
pub fn create_webdav_client_with_transport(WebdavConfig, &@moonhttp/transport.Transport) -> WebdavClient  // 测试/高级注入
pub async fn WebdavClient::put_file(path~ : String, data~ : Bytes, content_type?~ : String,
                                     on_progress?~ : (Progress) -> Unit) -> Unit

                                         on_progress?~ : (Progress) -> Unit) -> Unit   // 真流式
pub async fn WebdavClient::mkdir(path~ : String) -> Unit
pub async fn WebdavClient::delete(path~ : String) -> Unit
pub async fn WebdavClient::exists(path~ : String) -> Bool
pub async fn WebdavClient::list(path~ : String) -> Array[FileInfo]     // Depth:1，不含自身
pub async fn WebdavClient::stat(path~ : String) -> FileInfo            // Depth:0
pub async fn WebdavClient::move_path(src~ : String, dst~ : String, overwrite?~ : Bool) -> Unit
pub async fn WebdavClient::copy_path(src~ : String, dst~ : String, overwrite?~ : Bool) -> Unit
pub async fn WebdavClient::set_properties(path~ : String, props~ : Array[(String, String)],
                                          namespace?~ : String) -> Unit

                                          namespace?~ : String) -> Map[String, String]
```

根包 `webdav.mbt` 以 `typealias` + 薄函数重导出以上全部，用户侧统一 `@webdav.xxx`。

## 协议映射与关键实现点
- 所有请求统一 `with_validate_status(_ => true)`，由 WebDAV 层检查状态码，非期望状态转 `WebdavError::Api`（中文消息，如「MKCOL 失败: 409 父目录不存在」）。
- PUT(200/201/204)、GET(200)、MKCOL(201)、DELETE(200/204)、MOVE/COPY(201/204, Destination 为绝对 URL、Overwrite 头 T/F，默认 T)、PROPFIND(207, Depth 0/1)、PROPPATCH(207)、HEAD(200/404)。
- Basic Auth 走 `with_auth`；`Method::Other("PROPFIND"/"MKCOL"/"MOVE"/"COPY"/"PROPPATCH")` 原样落线（moonhttp 已有测试钉住）。
- XML 解析用 `NamespaceReader`，按 `local_name` + `namespace_uri == Some("DAV:")` 匹配（不依赖服务端前缀）；`resourcetype` 含 `collection` 子元素判目录；`propstat/status` 提取每属性状态码。
- 路径处理：base_url 与 path 拼接规范化；路径段 percent 编码（发请求）、href percent 解码（得显示名）；`move/copy` 的 Destination 用完整 URL。
- 进度：上传用 `with_on_upload_progress`（真实网络分块进度）；`get_file` 用 moonhttp 自动下载进度；`download_file` 流式循环内自行累计 loaded 并回调，total 取 Content-Length。
- 演示程序 `cmd/main` 改 `pub async fn main`，对本地/指定 WebDAV 服务器跑全流程。
